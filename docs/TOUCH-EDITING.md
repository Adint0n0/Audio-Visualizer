# タッチ編集

スマートフォンではプレビューと編集中のパネルを同時に表示します。下部の **シーン**、**レイヤー**、**編集**から開き、同じ項目かパネル内の閉じるボタンで戻れます。縦画面のパネルは高さを切り替えられます。横画面ではプレビューの隣に編集項目を置きます。画面の高さは動的ビューポートに合わせます。

| モード | 操作 | 結果 |
| --- | --- | --- |
| オブジェクト | タップ | 描画レイヤーを選択。空白では選択解除。細い要素の近くもヒット探索する。 |
| オブジェクト | 1本指ドラッグ | 選択対象を現在のカメラに平行な面で移動。親子階層の変換を反映。 |
| オブジェクト / 3D回転 | 2本指で移動・ピンチ・ひねり | 2本の中点を基準に、同時に移動、等比スケール、画面軸回転。指の本数の切り替えでその位置を次の基準にする。 |
| オブジェクト / 3D回転 | 長押し | 精密変形、中央への移動、選択へのフォーカス、重なった別レイヤーへの切り替え。 |
| 3D回転 | 1本指ドラッグ | トラックボール方式で立体回転。回転計算はクォータニオンを使用。 |
| 視点 | 1本指ドラッグ | 編集ビューの軌道回転。 |
| 視点 | 2本指で移動・ピンチ・ひねり | 編集ビューのパン、ズーム、ロール。方向メニューで正面・背面・側面・上面・斜めに切り替えられる。 |

デスクトップではマウスから同じモードを操作できます。従来の軸ギズモも使用できます。視点モードで **出力カメラに反映**を押すと、現在の編集ビューをプロジェクトの出力カメラへ確定します。**視点を戻す**で元の出力ビューを表示します。プレビュー右上の集中モードは画面全体をプレビューと操作に使います。設定内にはブラウザ対応時の全画面表示もあります。

レイヤー一覧からは、画面外や重なったオブジェクトを選べます。通常の目印はミント色の破線で、録画や動画書き出しには含まれません。ロック中は選択やフォーカスができ、変形は無効です。精密変形ではXYZを個別入力でき、位置、回転、倍率、ピボットをそれぞれ初期化できます。ステッパーの調整軸はローカルまたはワールドから選べます。数値欄は保存データと同じ親座標を表示します。

## スナップ

磁石ボタンでスナップ設定を開きます。位置吸着は画面上で投影した辺・中心とキャンバス、同じ描画空間の近隣レイヤーを比較します。グリッドは0.25シーン単位です。固定レイヤーの座標グリッドは画面固定空間のXY、3Dはワールド座標を用います。吸着対象を個別に切り替え、距離を0〜30 CSS pxに設定できます。吸着保持の解除距離は取得距離の1.6倍です。任意で対応端末の振動を使います。

2本指のひねりでは 1、5、10、15、30、45、90° または任意の刻みを選べます。吸着の基準は操作開始時のZ角に、その操作の画面上の回転を加えた角度です。3D回転中の各オイラー成分を丸める操作には精密変形を使います。倍率は25、50、100、150、200%と任意の刻みへ吸着します。精密変形の **隣のレイヤーと幅を揃える**は、同一空間の先頭の表示レイヤーの投影幅を基準に、XYZを等比で調整します。等間隔にはレイヤーツールの分布を使います。

連続する指の操作は指がすべて離れたときに履歴1件として確定します。キャンセル、ポインター捕捉の喪失、アプリ切替、向きの変更では確定前の結果を破棄します。調整中は画面に座標、角度、倍率と吸着ガイドが表示されます。

## 描画負荷

自動画質を有効にすると、プレビュー描画時間と連続再生時のフレーム間隔に応じて解像度を下げ、重い粒子・地形の密度を落とします。低い段階では残光の履歴パスを休止します。同じ設定でも書き出しは出力用解像度と保存されている密度でレンダリングします。画面固定の選択マークにも出力上の影響はありません。
