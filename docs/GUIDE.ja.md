# Formant Studio 利用ガイド

## 最初の一本を書き出す

1. アプリを開くと、デモ曲と 3D シーンが表示されます。再生ボタンで音と動きを確認できます。「素材を読み込む」かファイルのドロップで、端末内の音声または動画を選びます。読み込みと解析が終わるまで待ってください。素材の処理、編集、書き出しはブラウザ内で行います。
2. ライブラリでシーンを選び、プレビュー画像を確認します。「シーンを置換」で選んだシーンを適用します。「レイヤーを追加」では現在の構成にテンプレートのレイヤーが加わります。検索、カテゴリー、ハートのお気に入りを利用できます。
3. 「レイヤー」タブでオブジェクトを選びます。「プロパティ」でスタイル、要素数、感度、配色、不透明度を調整します。「詳細」を有効にすると、形状固有のパラメーター、材質、変調などの項目が開けます。
4. 波形をクリックまたはタップしてシークします。「範囲」を開き、開始・終了時刻を秒で入力するか、波形の両端のハンドルを動かします。ループをオンにすると選んだ区間を繰り返し再生できます。
5. 「書き出し」で形式、画面寸法、フレームレート、音声形式を指定します。コーデック試験が済んだら書き出しを開始します。完了後、ダイアログを閉じる前に動画をダウンロードします。レンダーは再生時間より長くかかる場合があります。

## レイヤーとシーンを編集する

- 「レイヤーを追加」からビジュアライザー、テキスト、画像、グループを作成できます。目のアイコンで表示を切り替えます。上の行ほど描画順が手前で、3D 形状の前後関係は深度テストにも従います。
- 複数選択ボタン、または Ctrl、⌘、Shift を押しながらクリックしてレイヤーを選びます。「レイヤー操作」から複製、削除、前面・背面への移動、ロック、グループ化、軸を選んでの整列・等間隔配置ができます。グループ化するレイヤーの親と座標空間を揃えてください。
- 「トランスフォーム」の X、Y、Z はローカル座標で、回転は度数です。スケールを等比固定できます。画面上では移動、回転、拡縮ツールの軸ハンドルをドラッグします。プレビュー設定のスナップ値を 0 より大きくすると一定刻みで操作できます。
- 「画面に固定」はタイトルやロゴを出力画面に留めます。グループは親として子の変形に作用します。詳細設定でピボット、親グループ、深度テストを変更できます。
- 音声に背景画像を付けるには、プロパティの「シーン」から背景画像を選びます。空のシーンでは背景色の初期値は黒で、テンプレートは独自の背景色を持ちます。動画入力では元映像が背景になり、その動画に含まれる音声が反応と出力に使われます。音声のない動画では反応が無音になります。
- スペクトラムには複数の配置と形状があります。「カスタムパス」で SVG のパスデータを直接入力するか、SVG ファイルの最初のパスを読み込みます。「折れ線として編集」で制御点を移動・追加・削除し、適用します。曲線から折れ線への変換は適用時に確定します。地形、ウォーターフォール、変形球体などは専用の配置を持ちます。
- グラデーションは色の位置を 0～1 で指定します。各レイヤーの外観で、そのレイヤーに適用するブルームと残像を設定できます。「シーン」では出力カメラ、照明、ブルーム、残像を調整できます。編集カメラで側面から確認したら、出力カメラに戻して最終構図を確認してください。縦長動画の場合はプレビューと書き出しの両方で縦長を選びます。

## 音に合わせる

詳細設定で「シーン」から「音声解析」を開きます。FFT サイズを大きくすると周波数を細かく区別でき、短くすると音の変化を時間軸上で捉えやすくなります。チャンネル、窓、周波数範囲、分布、平滑化などを設定し、「解析設定を適用」します。ここでの変更は描画用の解析に作用します。

レイヤーまたはシーンで「音声による変調」を開き、例えば「スケール · Y」に低音域を割り当てます。下限・上限周波数、感度、アタック、リリースを調整し、再生中の入力レベルを確認します。加算、乗算、置換は上から順に評価されます。オンセットは音の立ち上がりを表す信号です。「自動アニメーション」では回転、揺れ、軌道、ノイズなどの周期・振幅・位相を設定できます。

## 操作と保存

| 操作 | 方法 |
| --- | --- |
| 再生・一時停止 | Space または再生ボタン |
| 元に戻す・やり直す | Ctrl/⌘+Z、Ctrl/⌘+Shift+Z |
| 完全プロジェクト保存 | Ctrl/⌘+S または画面上部のプロジェクト名から保存 |
| 数値を確定 | Enter または別の欄に移動 |
| スマートフォン | 上部のタブからライブラリ、プレビュー、プロパティを切替 |
| 言語・全画面 | 上部の EN/JA、プレビュー右上の全画面ボタン |

キーボードショートカットは、テキスト入力欄やダイアログの外で使います。数値スライダーやギズモの 1 回のドラッグは 1 回の Undo で戻せます。

プロジェクトメニューの「素材を含めて保存 (.avproj)」で、素材、シーン、出力設定をまとめて別の端末へ渡せます。「シーン設定を保存 (.json)」は設定のみです。再リンクする際は元と同じ内容のファイルを指定します。単体のオブジェクト設定は「詳細」→「レイヤー設定」で保存し、同じ種類のレイヤーに読み込みます。「コピー」「貼り付け」では位置や親子関係を維持して外観と変調を複製できます。

オフラインで使用する前に「ガイド」を開き、「オフラインで利用できます」の表示を確認してください。自動保存は現在のサイトとブラウザに紐づきます。書き出し先や復元用ファイルとして、重要な編集後は .avproj をダウンロードしてください。自動保存に失敗した場合はプロジェクトメニューで容量を確認できます。アプリの静的ファイルはオンラインでの初回取得・検証後にキャッシュされ、同一サイトでオフライン利用できます。

## 書き出せないとき

- 入力時間は最大 30 分です。拡張子が同じでも、映像・音声のコーデックと端末の組み合わせで読み込めるファイルは異なります。
- プレビューが重い場合はプレビュー設定で描画倍率と FPS を下げます。最終出力の寸法や FPS は書き出し画面で設定します。
- 一辺 4096 px、総画素数 8,847,360、60 fps まで設定できます。実際に利用できる寸法、コーデック、品質モードは端末の試験結果に従います。条件に合う候補がない場合は書き出し設定を変更し、試験結果を確認してください。
- 空き容量の不足時は、出力区間・ビットレート・画面寸法を調整します。WebGL コンテキストを失った場合はプレビューを再試行し、書き出しをやり直します。
- 出力前の音声形式選択、コピー条件、端末負荷の実測、ファイル制限の詳細は、以下の資料を参照してください。
